Detailed Description

Append-only Merkle hash tree.

Stores leaf hashes and raw entry data in parallel dynamic arrays. The tree structure is computed on demand (not cached) — all proof and hash operations walk the arrays directly.

Ownership: the tree owns all allocated memory in its arrays. Call mtc_tree_free() to release.
