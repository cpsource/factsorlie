Detailed Description

Persistence and CA operations for the MTC CA server.

Manages all server-side state: the Merkle tree, issued certificates, checkpoints, landmarks, revocations, and the Ed25519 CA signing key. Supports two storage backends:

  • PostgreSQL (Neon) when MERKLE_NEON is available
  • File-based JSON in data_dir as fallback

The store owns all memory for its internal arrays (certificates, checkpoints, revocations). Call mtc_store_free() to release.

Thread safety: NOT thread-safe. All operations must be serialised.
