Generate a consistency proof between two tree sizes.

Computes the Merkle consistency proof from old_size to new_size, per RFC 9162 Section 2.1.4.

Parameters
[in]treeMerkle tree.
[in]old_sizeSmaller tree size (>= 1).
[in]new_sizeLarger tree size (<= tree->size).
[out]proof_outReceives a malloc'd buffer of hashes (each MTC_HASH_SIZE bytes). Caller must free().
[out]proof_countReceives the number of hashes in the proof.
Returns
0 on success. -1 if old_size < 1, new_size > tree->size, or old_size > new_size.

Generate an inclusion proof for a leaf.

Computes the Merkle inclusion path for leaf index within the subtree [start, end), per RFC 9162 Section 2.1.3.

Parameters
[in]treeMerkle tree.
[in]indexLeaf index to prove.
[in]startSubtree start (inclusive).
[in]endSubtree end (exclusive).
[out]proof_outReceives a malloc'd buffer of sibling hashes (each MTC_HASH_SIZE bytes). Caller must free().
[out]proof_countReceives the number of sibling hashes.
Returns
0 on success. -1 if index is out of [start, end) or end > tree->size.
