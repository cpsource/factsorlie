Detailed Description

Central state container for the MTC CA server.

Aggregates the Merkle tree, CA identity, signing key, issued certificates, checkpoints, landmarks, and revocations. Created by mtc_store_init() and destroyed by mtc_store_free().

Ownership: the store owns all json_object pointers in the certificates and checkpoints arrays (ref-counted via json_object_get/put).
