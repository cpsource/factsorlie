int mtc_db_create_nonce ( PGconn *  conn,
const char *  domain,
const char *  fp_hex,
int  ca_index,
char *  nonce_out,
long *  expires_out 
)

Create a cryptographically random enrollment nonce.

Generates a 256-bit random nonce via wolfCrypt, inserts it into the mtc_enrollment_nonces table with status 'pending', and returns the hex-encoded nonce and expiration timestamp. Stale nonces are expired first. Returns -1 if a pending nonce already exists for the given domain+fp pair (prevents duplicate enrollment requests).

Parameters
[in]connActive PostgreSQL connection.
[in]domainDomain name bound to this nonce.
[in]fp_hexPublic key fingerprint (hex string) bound to this nonce.
[in]ca_indexLog index of the issuing CA (-1 for CA self-enrollment via DNS).
[out]nonce_outBuffer for the hex nonce. Must be at least MTC_NONCE_HEX_LEN + 1 bytes.
[out]expires_outReceives the UNIX expiration timestamp.
Returns
0 on success. -1 on failure (duplicate pending, RNG error, or DB error).

◆ mtc_db_get_connstr()

const char * mtc_db_get_connstr ( void  )

Resolve and return the PostgreSQL connection string.

Searches for MERKLE_NEON in the following order:

  1. $MERKLE_NEON environment variable
  2. –tokenpath file (MERKLE_NEON= line)
  3. ~/.env fallback (MERKLE_NEON= line)

The result is cached after the first successful lookup.

Returns
Pointer to an internal static buffer containing the connection string, or NULL if not found. Caller must NOT free.

int mtc_db_validate_and_consume_nonce ( PGconn *  conn,
const char *  nonce_hex,
const char *  domain,
const char *  fp_hex 
)

Atomically validate and consume a nonce in a single query.

Issues a single UPDATE ... WHERE (pending + unexpired + matching) to eliminate the TOCTOU race between validate and consume. If zero rows are affected, the nonce was invalid, expired, or already consumed.

Parameters
[in]connActive PostgreSQL connection.
[in]nonce_hexHex-encoded nonce to validate and consume.
[in]domainDomain to match (NULL or "" to skip check).
[in]fp_hexFingerprint to match (NULL or "" to skip check).
Returns
1 if the nonce was valid and is now consumed, 0 otherwise.
