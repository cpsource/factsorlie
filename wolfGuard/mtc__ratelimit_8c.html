int mtc_ratelimit_check ( const char *  ip,
int  category 
)

Check whether a request from ip is allowed.

Increments both the category-specific and RL_GLOBAL counters for the given IP in Redis, then compares against the configured limits. If Redis is not connected, the request is always allowed (fail-open).

Parameters
[in]ipClient IP address string. NULL or empty = allow.
[in]categoryRate limit category (RL_READ..RL_REVOKE). Invalid values = allow.
Returns
1 if the request is allowed. 0 if rate-limited (either category or global limit exceeded).
Note
The counters are always incremented, even when the request is ultimately denied — this is intentional to prevent burst abuse.
