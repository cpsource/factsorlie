Cosign a subtree range [start, end) with the CA Ed25519 key.

Builds the MTC subtree signature input per the MTC draft specification and signs it with the CA's Ed25519 private key.

Parameters
[in]storeStore (provides CA key and tree).
[in]startSubtree start index (inclusive).
[in]endSubtree end index (exclusive).
[out]sig_outBuffer for the signature (must be >= 64 bytes).
[out]sig_szReceives the signature size in bytes.
Returns
0 on success, non-zero wolfCrypt error code on failure.
