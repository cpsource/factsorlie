Initialise the logging subsystem.

Opens the log file for appending (creates the parent directory if needed). Sets line-buffered mode so messages appear promptly. On failure, falls back to stderr.

Parameters
[in]log_filePath to the log file. NULL defaults to /var/log/mtc/mtc_server.log.
[in]levelInitial log level (MTC_LOG_ERROR..MTC_LOG_TRACE).
Returns
0 on success. -1 if the log file could not be opened (logging falls back to stderr).
